> 2026-06-01. Triggered by user challenge: "did the flow reference the suggested open research, or did you imagine it?" Answer: the loop was synthesized from spec + escape-mrc WITHOUT reading GPT Researcher / Open Deep Research source. Two opus agents then read the actual source (GPTR `gpt_researcher`/`multi_agents`/`deep_research`; ODR `deep_researcher.py`/`state.py`/`utils.py`). This audit synthesizes a full re-read of PRODUCT-SPEC §0–30 + both studies, and concludes **P1–P6 should be updated** (6-phase structure preserved; P1 gains the correct loop *shape* as deterministic skeleton).

## Revised canonical flow (incorporating Bucket B)

```
intake
 → scope (clarify gate; H0)            [B1]
 → write_brief (north-star)            [B1]
 → issue_expansion (grounded)          [A4,B3]
 → select_branch / SUPERVISOR          [B2]
     └─ fan-out N isolated workers (concurrency cap):  [B2,B5]
          research_worker → source_critic(cheap) → compress   [B4,B7]
 → skeptic / counterargument           [A4,B8]
 → albert_audit (typed clean|challenges) [B8]
 → artifact_update (compressed, dedup)  [B4]
 → readiness_scoring (+plateau)         [A5]
 → anti_premature_checklist            [A3]
 → cos_decision (staged binary gates; branch-budget; exhaustion; emission-gate) [A3,B9,B10]
 → router: continue/branch/rerank/pull(interrupt)/push(interrupt)/synthesize/pause/terminal  [B6]
```

## Net effect on phases

- **6-phase structure SURVIVES.** P1 still = deterministic, zero-LLM, fully testable.
- **P1 grows** (in size, not intelligence): the graph now has the FULL correct node shape (scope, brief, supervisor fan-out, compress, two-level caps, anti-premature checklist, branch budget, staged decision) — but every new node is a deterministic stub/passthrough. This avoids a structural rewrite in P2–P4.
- **P2** fills in: real brains + grounded decomposition + real compression + typed-exit Albert.
- **P3** fills in: interrupt()-based H0–H6 + auto mode + interactive clarify.
- **P4** fills in: real fan-out workers + two-altitude source ranking.
- **P5/P6** unchanged (synthesis/memo; hardening).

## Decision for user

Update `flow-diagram.md` + master backbone + the (uncommitted) P1 spec & plan to this revised shape, THEN build P1. P1 stays deterministic but gets the right skeleton so later phases are fill-in, not rewrite.
